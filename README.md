# Velorum Shopify Sections

This repository contains `Velorum-Premium-Sections-v1.zip`, a packaged set of Velorum Shopify theme sections. The archive is the primary deliverable; the repository does not contain a standalone runnable app.

## Use

Download the ZIP and inspect its contents before adding any section to a Shopify theme. Test changes in a duplicate or unpublished theme before publishing them to a storefront.

For a more complete project history and source files, see the separate private Velorum repository if you have access.
